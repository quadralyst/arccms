Manage media

Every image on the site comes from the Media Manager, which stores each upload in four sizes (a GIF is stored once, as it is). Set the sizes once before you upload, then pick images wherever the editor asks for one. The full reference is Media.

Set the sizes first

  1. Open Settings, then Miscellaneous.

  2. Under Media Upload, set Max image size (px, longest side) to the widest image your design shows. The default, 1200, gives S 300, M 600, L 900 and XL 1200 pixels on the longest side. Images are never enlarged: a size the image is too small for stores it at its own size, under that size's name.

  3. Set Max File Size (MB) (5 by default). Leave Convert all images to WebP on, as it is by default, for smaller pages (GIFs are left alone).

  4. Press Save Media Settings.

Sizes are made when an image is uploaded, so settle them before you upload your library.

Upload images

Open Media Manager in the admin menu and press Upload New, then drop an image or browse for one. It takes JPEG, PNG, WebP and GIF.

Optional: to search free stock photos from Unsplash inside the Media Manager, add your Unsplash keys in Settings, Integrations. The page there walks you through getting them.

Use images in content

  • Cover image: in the editor's Basic tab. It is the list card image, the social sharing image and the search thumbnail.
  • In the body: insert an image from the editor toolbar and choose its Size (M unless you choose).
  • Image and gallery fields: custom fields open the same library; a gallery's Add photos picks several at once, in the order you click them.

Use sizes in templates

In a template, any image from the Media Manager also has its four sizes: add _s, _m, _l or _xl to the name. Each size bounds the longest side, so M fits a 600 pixel box whether the photo is wide or tall. For a list card, the small or medium size is enough:

<img src="{{ coverImage_m }}" alt="">

The plain name, such as {{ coverImage }}, gives the image as it was picked. A GIF is stored once, so its four sizes all give the original file. See Design templates.

Every image uploaded now is stored under all four size names. An image uploaded with an older version that was smaller than the maximum may lack some sizes, so a size name can point at a file that does not exist. To fix one, upload it again and pick the new copy where it is used.
