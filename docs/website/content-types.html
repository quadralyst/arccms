Define content types

Turn each content type from your plan into a type in the admin area, then write and publish one item to see the whole flow work. The full reference is Content.

Create a content type

  1. In the admin menu open Content, then Content types, and press Add Content Type. (Articles is already there from the first-run wizard; edit it rather than adding a second one.)

  2. Fill in Content Type Name (Plural) and Singular Name, for example Case Studies and Case Study. The plural heads the list page and the admin menu; the singular labels buttons such as Add Case Study.

  3. Check the Content Type Slug. It is filled in from the name and becomes the URL: case-studies gives /case-studies. Lowercase letters, numbers and hyphens only.

  4. Add a Description (shown under the list page heading) and pick an Icon (Font Awesome) for the admin menu.

  5. Leave Generate public pages on, unless the items are only shown inside other pages.

  6. Pick a Content Template. Start with Default Template; you can switch to your own folder after Design templates.

  7. Under Custom fields, press Add Field for each extra field in your plan: give it a Name, a Type and, if it must be filled in, tick Required.

  8. Press Save Content Type. The type appears in the admin menu under Content.

When you edit a saved type, its form has two more sections you come back to later: Searchable custom fields (see Add search) and Structured data (see Get found by search engines and AI).

Changing the slug of a type that already has published items breaks every existing link to them. Settle the slug before you publish.

Choose field types

TypeHolds
text, numberA short text or a number, such as a subtitle or a price
richtextFormatted text with its own editor
date, datetimeA date, or a date and time, such as an event start
image, icon, colorAn image from the media library, an icon, a color
booleanA yes or no
dropdown, radio, checkboxA choice from options you list, separated by commas, or from the items of another content type (Use data from another collection)
infocardRepeating cards, each an icon or image with a headline and a paragraph
galleryRepeating photos and YouTube videos with captions
labelvalueRepeating label and value pairs, such as an at-a-glance box
maplocationRepeating places with an address and a map pin

Each field gets a key from its name, shown under the name as you type. Templates use that key, and it is fixed once the type is saved, so name fields carefully. Do not add fields for what every item already has (title, URL slug, cover image, body, summary, dates, tags, author).

The default template already shows three repeating fields, with no template work, when they are named exactly Gallery (a gallery field), Details (a labelvalue field) or Locations (a maplocation field). Any other repeating field needs a template that loops over it.

Write and publish an item

  1. Open the type in the admin menu under Content, and press Add followed by the singular name.

  2. Write the title and the body. The editor has headings, lists, tables, images, links and code, plus ready-made blocks (FAQ, Key takeaways, How-to steps, Definition) from the toolbar's grid icon.

  3. In the Basic tab, fill in the Summary (used in lists and as the default SEO description), check the URL Slug, and pick a Cover Image, Tags, an Author and the custom fields.

  4. Press Preview. It saves a draft and opens the page in a new tab, rendered with the type's template.

  5. Press Publish. The page is written to the live site, and the list page, sitemap and feeds are updated.

Save as draft keeps work unpublished; the editor also saves as you type. The History tab keeps earlier versions you can restore. From the content list you can Unpublish an item, choose the Columns shown, and Bulk Import items from a CSV or Excel file.
