Add authors and tags

Authors put a named person on every page, which readers, search engines and AI assistants all trust more. Tags group items by topic and pick the related items shown under each page. Set up both before editors start writing. The full reference is Authors and tags.

Add authors

  1. Open Content, then Authors, and press New author.

  2. Fill in Name, Role or job title and a Short bio of two or three sentences. Add a Photo URL, a Website or profile page, and under Profiles elsewhere one profile link per line (LinkedIn, X, GitHub).

  3. Press Create author. Repeat for everyone who writes.

  4. On the main author, choose Use as default for new content. New items then get that author automatically.

Editors pick the author of each item in the editor's Basic tab. The published page shows the byline and an author box, and tells search engines who wrote it.

Deleting an author keeps their name on the items that named them, as plain text, but drops the bio, photo and links.

Add tags

Tags belong to one content type: Articles and Case Studies each have their own. There are two ways to add them:

  • While writing (the quick way): type in the editor's Tags field and press Enter on a new name to create it.
  • Up front, to set colors: open Content types, choose Manage Tags on the type, and add each tag with a Tag Label and a Tag Color.

Keep a short, fixed list per type, and give every item at least two. Tags are shown on the page, sent to search engines as keywords, and used to choose related items.
