Use the admin area

The admin area is where the people who run a site or an app write content, manage contacts, send email and change settings. This page is a map of it. Each area links to the page that explains it.

Get in

Sign in with an admin account and open /admin/dashboard. The menu is on the left. The first person to sign up on a new install becomes the admin (see Create the first admin); other roles are described in Users and roles.

What you see in the menu depends on the features the site has. A feature that is switched off has no menu item, no page and no settings tab. See All features.
