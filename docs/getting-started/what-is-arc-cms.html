What is Arc CMS

Arc CMS is an open-source content management system that runs on your own Firebase project. You use it to build a website, or you copy it and build your own app on top of it.

In plain words

Arc CMS gives you an admin area where you define content types, write and publish content, design how it looks with HTML templates, collect sign-ups and send email. Everything it stores lives in your Firebase project: Firestore for data, Firebase Authentication for accounts, Cloud Storage for files and Cloud Functions for the work that has to happen on a server.

When you publish, Cloud Functions write the page as a static HTML file to Firebase Hosting. Visitors get plain, fast pages; the admin area and the member area are an Angular app served from the same site.

What you get

There is no server of your own to run. The build ships the app as static files. Your home page and content are published as static pages, and all server work happens in Cloud Functions. See Architecture for how the parts fit.

Who it is for

  • Developers who know web development and want a content site, or an app with sign-in, email and payments, without building those parts again.
  • Teams that run the site: editors and admins who write content, manage sign-ups and send email from the admin area, without touching code.

What it is not

  • Not a hosted service. You run it on your own Firebase project and pay Google for what it uses.
  • Not a drag-and-drop page builder. Pages are shaped by HTML templates that a developer writes once.
  • Not for another backend. It is built on Firebase and needs a Firebase project; it does not run on another database or host.
  • Not something you edit freely in an app. An app built on a copy keeps its own code in the custom space and leaves the Arc CMS files alone, so updates merge cleanly (see Core and custom).
