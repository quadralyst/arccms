All features

An app built on Arc CMS chooses which features it has. A feature that is off has no menu item, no page, no settings tab, no dashboard card and no Cloud Function. Its data stays, and turning it back on brings everything back.

Features you can switch

Eleven features can be switched. Ten are on unless the app lists them in off. The installable app (pwa) is off unless the app lists it in on. The choice is made in src/custom/features.ts: see Choose your app's features and Choose your website's features.
