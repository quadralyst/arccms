Media

Upload images once and use them everywhere: the media manager stores each upload at four sizes, converts it to WebP, crops to a ratio or a free shape, and lets editors pick an image and a size wherever a field wants one.

What it is

The media manager is at Media Manager in the admin menu (/admin/media) and opens as a picker from every image field. It has these tabs:

TabGives
My UploadsEvery upload in the library, newest first, 20 per page. Drop or choose several files at once.
Free ImagesSearch Unsplash photos, once an Unsplash key is set in Settings > Integrations. A chosen photo is used from Unsplash by its URL; it is not copied into your storage.
IconsThe Font Awesome icon picker. Shown only when an icon field opens the picker.

Where the picker opens:

  • The content editor: cover image, image fields, images in the body, and rows of gallery and info card fields (a gallery can take several images in one pick).
  • The signup form editor.
  • An admin's profile photo. Members upload their photo to their own folder instead (avatars/{uid}/); they never see the library.

Turn it on or off

Media is always on. It is core and belongs to no switchable feature.

Set it up

Nothing is needed: uploads work on a new install. To change the limits, open Settings > Misc, Media Upload:

SettingDefaultStored as
Max File Size (MB)5Settings/misc.mediaMaxFileSize
Max image size (px, longest side)1200Settings/misc.mediaMaxSize
Convert all images to WebPOnSettings/misc.mediaConvertToWebp

To offer Unsplash, add an Unsplash access key under Settings > Integrations; the page has a setup guide. For choosing and organizing a website's images, see Manage media.

Use it

Upload

The manager accepts JPEG, PNG, WebP and GIF. Each file is processed in the browser, then uploaded:

  1. It is resized to four sizes, each a limit on the longest side, so a size means the same box for landscape and portrait photos.

  2. It is encoded as WebP (unless conversion is off). A size the image is too small for is not enlarged; sizes with the same pixel size share one file.

  3. The largest file is checked against the file size limit. Too large, and the upload stops with a message.

  4. The files go to Storage and one media document records them.

SizeLongest sideDefaultTypical use
SA quarter of the maximum300pxThumbnails, list cards
MHalf600pxThe size an editor gets unless they choose
LThree quarters900pxArticle bodies
XLThe maximum1200pxCovers, heroes, the social share image (the cover picker opens at XL)

GIFs are stored once, as they are, so animation survives: they have no sizes.

Pick an image

In the picker, choose an image and a size (S, M, L or XL), then confirm. The field stores that size's URL. Templates can still use any other size of the same image through {{ key_s }} to {{ key_xl }}; see Templates.

Crop

Select one image and press Crop under its preview. The crop step takes the place of the grid:

  • Pick a ratio: Free, Original (the image's own shape), 1:1, 4:3, 3:4, 3:2 or 16:9. The frame starts as the largest centred one of that shape (Free starts as the whole image).
  • Drag inside the frame to move it, and drag a corner or an edge to resize it. With a ratio, every handle keeps it. The arrow keys move the focused frame, with Shift for bigger steps.
  • Below the image is the size the crop will be. When it is smaller than the size picked in the side panel, a note says so: the image is never enlarged, so it may look soft in a large space.

What applying a crop does depends on where the image comes from:

ImageApplying the crop
An upload (My Uploads)Save cropped copy saves the crop as a new image, at all four sizes, and selects it. The original is not changed, because content may already use it. The copy is cut from the original's XL file, the largest one kept, and goes through the same size, WebP and file size rules as an upload.
An Unsplash photo (Free Images, in the picker only)Apply crop keeps the crop for this pick. Nothing is copied: the inserted URL asks Unsplash for the cropped photo (its rect setting, in the photo's original pixels), so the photo is still used from Unsplash. Every size a template derives keeps the crop. Remove crop goes back to the whole photo.

Crop is not offered for GIFs (it would drop the animation), or when the picker is choosing several images at once.

Delete

Deleting an item in the media manager removes every stored size from Storage and the media document.

Delete does not check whether content uses the image. Pages that show it break, including published pages. Search your content before deleting an image.

Move media to another project

Data > Export Files and Import Files copy media files; see Data import and export.

Extend it

  • Open the picker from your own admin page by opening MediaManagerComponent (in src/app/pages/admin/(media)/media.page.ts) as a dialog with { isDialogOpen: true }. Options: multiple (several images), size (the preselected size), cropRatio (the ratio the crop frame opens with, such as '1:1' for a square slot; Free when omitted), allowIcons and allowImages (which tabs show). It returns mediaUrl, mediaUrls and size.
  • Files your app lets members upload belong in their own folders under rules you write in storage.app.rules. See Set security rules and indexes.

What it stores

WhereWhat
Storage mediaImages/{name}-{random}-{size}.webpThe sized files (-s, -m, -l, -xl); the original extension instead of .webp when conversion is off. GIFs: mediaImages/{name}-{random}.gif. The name comes from the file name, lowercased and hyphenated. A cropped copy is named after its original with -crop. With an upload folder configured for the install, every path starts with it (see Configure a project).
media/{id}downloadURL (the XL file), name, uploadTime, width, height, and variants: for each size its url, Storage path, width and height. GIFs have no variants. A cropped copy is a document like any other upload.
Settings/miscThe upload settings above
Settings/integrationsThe Unsplash keys (admin only)
Cloud FunctionKindDoes
searchUnsplashCallableSearches Unsplash with the key kept server-side, 20 results per page
readMediaImageCallableAdmins only: returns the bytes of an upload's XL file (from its media document, never a path the caller names) so the browser can crop it. GIFs and files over 7 MB are refused.

Resizing and cropping happen in the browser; no function processes uploads. To crop an upload, the browser gets its XL file's bytes through readMediaImage, because a canvas may only export an image its page is allowed to read, and a Storage bucket sends no cross-origin header unless it was given a CORS setup. The crop frame itself shows the image by its normal URL, so it appears at once; the bytes are fetched on Save cropped copy.

Troubleshooting

SymptomCause and fix
"... exceeds the maximum allowed size"The XL file is over the limit. Raise Max File Size, or lower Max image size.
"Invalid file type"Only JPEG, PNG, WebP and GIF are accepted. Convert SVG, HEIC or other files first.
Free Images asks for setupNo Unsplash access key in Settings > Integrations.
Upload fails with a permission errorThe account is not an admin, or the Storage rules are not deployed.
A size binding such as {{ coverImage_l }} shows a broken imageThe upload was smaller than that size's limit, so that size shares a larger size's file and the derived address has no file. Upload images at least as large as Max image size.
Size bindings are emptyThey are derived only for Media Manager uploads (under mediaImages/, in the install's upload folder if it has one) and for Unsplash photos. An image pasted from elsewhere gets none: bind the stored URL.
Changing Max image size did nothing to old imagesSettings apply to new uploads only.
No Crop buttonThe image is a GIF, the picker is choosing several images, or it is an Unsplash photo on the Media Manager page itself (crop it in the picker, where it is inserted).
"Could not load the image to crop"The image's file is gone from Storage or Unsplash, or the network dropped. Reload and try again.
"Could not save the cropped image" with a permission or not-found errorThe functions are not deployed since cropping was added (readMediaImage is missing), or the account is not an admin. Deploy the functions.
A cropped copy looks softThe crop is smaller than the size used where it shows. Crop a larger area, or upload a larger original.
