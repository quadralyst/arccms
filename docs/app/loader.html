Show that a page is loading

Every admin page shows the same loader while its data is on the way: a shimmer in the place of what is coming. Use it on your own pages, so they look the same and you get every later fix. It has a name a screen reader says, and it stops moving for someone who asks their device for less motion.

Use it

Import LoaderComponent and show it while your page waits:

import { LoaderComponent } from '../../shared/components/loader/loader.component';

@Component({
  standalone: true,
  imports: [LoaderComponent],
  template: `
    @if (loading()) {
      <arc-loader kind="rows" [count]="5" label="Loading orders" />
    } @else {
      ...
    }
  `,
})

A list made with app-global-table already has it: pass [loading].

Its options

InputWhat it doesWithout it
kindThe shape of what is coming: lines for text, rows for a list or a table, block for a card or a picturelines
countHow many lines, rows or blocks to draw. Draw about as many as will come, so the page moves as little as possible when they do3
labelWhat a screen reader says, such as "Loading orders""Loading..." in the person's language

Beside another loader on the same screen, such as a shimmer under a list that has its own, add aria-hidden="true", so a screen reader says it once.

Change its look

Set these in src/custom/styles.css:

VariableWhat it setsDefault
--arc-loader-baseThe colour of a bar#e9ecef
--arc-loader-shineThe colour that moves across it#f6f7f9
--arc-loader-heightThe height of a barSet by its kind

When to use something else

  • A button that is working keeps its own small spinner: nothing is coming to take its place.
  • Work with a known end, such as an upload or an import, shows a progress bar.
  • A wait on the server with no data coming, such as a sign-in step, says so with arc-wait-line (While the page waits on the server).
